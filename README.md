# 우신중학교 QUIZ SHOW (카훗 스타일)

학생은 자기 스마트폰으로 입장하고, 선생님이 진행 화면(프로젝터)에서 퀴즈를 시작하는 실시간 퀴즈 웹앱입니다.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (화면·로직 한 파일) |
| `firebase-config.js` | **Firebase 접속 정보** — 여기만 채우면 됩니다 |
| `assets/mascot.webp`, `assets/mascot-face.webp` | 마스코트 이미지 (배경 투명) |
| `assets/quiz-bgm.m4a` | 대기실·문제 풀이 배경음악 (저작권·사용 허락 확인 필요) |

## 사용 방법
**학생**: 상단 `참가자 입장` → 우리 반(1~3학년 × 1~4반) 선택 → 학번·이름 입력 → 입장.
문제가 나오면 보기를 한 번 누르면 바로 제출됩니다.

**선생님**: 상단 `관리자` → 비밀번호 → **내 퀴즈** 대시보드.
1. `＋ 새 퀴즈 만들기`(또는 복제·JSON 추가)로 퀴즈를 여러 개 저장해 둡니다. 문제를 고친 뒤에는 편집 화면에서 `💾 저장하기`.
2. 진행할 퀴즈의 `▶ 시작` → **대기실**이 열립니다. (퀴즈 제목 · 큰 QR · 입장한 학생 목록 · 배경음악)
3. 학생들이 입장하면 `🎮 게임 시작`을 눌러야 비로소 문제가 시작됩니다. (QR만 띄우거나 대기실에 들어가는 것만으로는 시작되지 않아요)

**대형화면(프로젝터) 전용 화면**: 노트북·PC에서 `주소?screen` (예: `https://…/index.html?screen`)을 열고 전체화면으로 띄우세요. 진행 화면의 `🖥 대형화면 열기` 버튼이 주소를 알려줘요.
설정·진행 버튼이 전혀 없고 대기실(QR)·문제·순위만 나옵니다. 배경음악도 이 화면에서 재생돼요. 진행은 선생님 폰(또는 다른 PC)에서 하면 됩니다.

**폰으로 진행**: 폰에서 관리자로 들어가 ▶ 시작 → 게임 시작을 누르면 그 폰이 진행자예요. 진행 중에는 화면을 켜 두고 인터넷 연결·탭을 유지해야 합니다. 다른 기기로 넘길 땐 `내 퀴즈 → 이어서 진행` 또는 `진행자 권한 가져오기`.

**배경음악**: 대기실~문제 풀이 중 재생되고 정답 공개부터 멈춥니다. 브라우저 정책상 대형화면에서 화면을 한 번 클릭해야 시작될 수 있어요. 대형화면이 켜져 있으면 진행 폰에서는 음악이 나오지 않습니다.
진행 화면 단축키: `Space`/`Enter` 다음 단계, `F` 전체 화면.

진행 순서: 대기실 → 게임 시작 → 문제 소개 → 문제 시작 → 답안 마감 → 정답 공개(자동 배점) → 이번 문제 순위(개인/반) → 개인 누적 순위 → 반별 누적 순위 → 다음 문제 … → 최종 결과(개인 TOP3 + 반별 순위).

## 1. 로컬에서 먼저 확인 (Firebase 없이)
`firebase-config.js` 가 비어 있으면 **테스트 모드**로 동작합니다. `index.html` 을 크롬으로 열고 탭을 두 개 열어
한쪽은 관리자, 한쪽은 참가자로 확인해 보세요. (같은 브라우저 안에서만 연결돼요. 학생 폰과는 연결되지 않습니다.)

## 2. Firebase 설정 (학생 기기와 실시간 연결하려면 필수)
1. https://console.firebase.google.com → **프로젝트 추가** (Analytics 는 꺼도 됩니다)
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: 가까운 지역(예: 싱가포르 `asia-southeast1`)
   - 보안 규칙: **테스트 모드로 시작** 후 아래 3번 규칙으로 교체
3. **규칙** 탭에 아래 내용을 붙여넣고 **게시**
```json
{
  "rules": {
    "festival2026": {
      ".read": true,
      ".write": true,
      "players": {
        "$pid": { ".validate": "newData.hasChildren(['name','g','c','num']) && newData.child('name').isString() && newData.child('name').val().length <= 20" }
      },
      "answers": {
        "$qid": { "$pid": { ".validate": "newData.child('choice').isNumber() && newData.child('choice').val() >= 1 && newData.child('choice').val() <= 4" } }
      }
    }
  }
}
```
4. **프로젝트 설정(⚙) → 내 앱 → 웹(</>) 앱 추가** → 표시되는 `firebaseConfig` 값을 `firebase-config.js` 에 복사
   (`databaseURL` 이 반드시 들어 있어야 해요. 없으면 Realtime Database 생성 후 다시 확인)
5. 파일을 저장하고 배포(또는 새로고침)하면 상단의 노란 `테스트 모드` 안내가 사라지고 관리자 화면에 `🟢 실시간 연결`이 표시됩니다.

## 3. 알아두면 좋은 점
- **문제·정답·점수 규칙은 ‘저장하기’를 누르면 암호화되어 Firebase(`festival2026/adminCfg`)에 저장**됩니다. 어느 기기에서든 관리자 로그인만 하면 같은 문제로 이어서 진행할 수 있어요. (‘문제 샘플로 초기화’ 후 저장하기 전까지 유지)
  학생 기기에는 정답 공개 전까지 정답이 전달되지 않아요. 암호 키는 관리자 비밀번호에서 만들어지므로, 비밀번호(`ADMIN_PW`)를 바꾸면 이전에 저장한 설정은 읽을 수 없어요. 바꾸기 전에 JSON 내보내기로 백업하세요.
- 진행은 **‘실시간 퀴즈 쇼 진행’을 누른 기기**가 맡습니다(타이머·점수 계산). 진행 중에 그 기기를 닫지 마세요.
  새로고침해도 이어지고, 다른 기기에서는 `진행자 권한 가져오기`로 넘겨받을 수 있어요.
- 관리자 비밀번호는 화면 잠금 수준입니다(코드에 포함). 행사용으로는 충분하지만 높은 보안이 필요한 용도에는 맞지 않아요.
- Firebase 규칙은 행사용으로 열어 둔 상태입니다. **행사가 끝나면 규칙을 잠그거나(`false`) 데이터를 삭제**해 주세요.
- 같은 반·학번에 다른 이름으로는 입장할 수 없어요(대리 입장 방지). 잘못 등록되면 관리자 설정 > 참가 현황에서 삭제하세요.
- 반별 순위 기준은 기본이 **1인 평균 점수**입니다(반별 참가 인원이 달라도 공정하게). 관리자 설정에서 ‘합계’로 바꿀 수 있어요.
